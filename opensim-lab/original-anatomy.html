Исходник: Framingham Heart Study, OpenSim 4.x. Используется конкретная модель, для которой заранее рассчитаны глобальные преобразования каждого сегмента.

Геометрия строится из VTK PolyData (.vtp). Рёбра в этом архиве представлены линейными сетками, остальные кости — треугольными поверхностями. Исходные файлы остаются внутри ZIP на твоём устройстве.

Важное различие

Ограничение исходной модели: лопатки жёстко соединены с ключицами (WeldJoint), поэтому нельзя использовать этот риг для достоверного движения лопаток при отжиманиях. Видимая кость ≠ независимо двигающийся сустав. В выбранной научной модели череп и семь шейных позвонков прикреплены к одному сегменту head_neck. Аналогично каждая кисть с фалангами — один сегмент без независимой анимации пальцев. Для точных отжиманий и хвата понадобится отдельная проверенная кинематика.

Без исходного архива можно видеть только наше старое схематичное отображение. Оригинальный ZIP содержит сотни поверхностей и 250 индивидуальных моделей; здесь используется одна модель с рассчитанными координатами. Отдельной геометрии ног в этой модели нет.
