# Мои тренировки
Персональный домашний тренировочный журнал на русском языке, адаптированный под iPhone.

## Публикация через GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root) → Save. 
Ссылка: https://AlexBorovinskiy.github.io/home-workouts/

## Установка на iPhone
Откройте ссылку в Safari → Поделиться → На экран «Домой».

## Данные
Записи хранятся только локально в браузере устройства и не отправляются в GitHub. 
В разделе «Данные» регулярно экспортируйте резервную копию JSON. Файл можно отправлять в ChatGPT для анализа и импортировать обратно обновлённый план.
Не размещайте JSON с персональными записями в публичном репозитории.


## Google Drive (личная облачная синхронизация)
1. В Google Cloud Console создайте проект, включите **Google Drive API**.
2. Настройте Google Auth Platform → Branding/Audience (для личного использования добавьте свой Google-аккаунт как тестового пользователя, если требуется).
3. В Data Access добавьте scope `https://www.googleapis.com/auth/drive.file`.
4. Clients → Create client → Web application. Разрешённый JavaScript origin: `https://alexborovinskiy.github.io` (без пути `/home-workouts`).
5. Скопируйте только **OAuth Client ID** вида `…apps.googleusercontent.com`. Никогда не добавляйте Client Secret в HTML, JS или GitHub.
6. В iPhone-приложении откройте «Данные», вставьте Client ID и нажмите «Подключить Google».
7. Приложение создаст приватный файл `Мои тренировки — журнал.json` на Google Диске и будет сверять изменения после сохранённых тренировок, пока авторизация активна.

Файлы журнала не отправляются в репозиторий. Доступ запрашивается через ограниченный scope `drive.file`.
Для Google Drive авторизации может потребоваться повторный вход при следующем запуске приложения или после истечения токена.
Если одновременно изменились локальная и облачная версии, приложение останавливает перезапись и предлагает явное объединение.
Локальные записи не пропадают при отсутствии интернета, однако делайте ручные резервные копии перед переносом данных на новое устройство.

### Анализ ChatGPT
Для чтения файла из ChatGPT пользователь отдельно подключает Google Drive в ChatGPT и предоставляет доступ к своему аккаунту. Возможность прочитать именно JSON-файл необходимо проверить после первой синхронизации. Если плагин не поддержит формат, сохраните или отправьте JSON через приложение.

## Сопоставление тренировок с Garmin
Перед тренировкой запустите силовую активность на Garmin и нажмите «Начать тренировку» в журнале в пределах одной минуты. Вводите повторения или секунды после подходов как обычно; отдельная кнопка таймера отдыха необязательна. При завершении нажмите «Завершить и сохранить». Существующий JSON (schemaVersion: 1) дополнительно хранит `startedAt`, `endedAt`, `durationSec` и `entries[].sets[].recordedAt` в UTC ISO 8601 (длительность в секундах). `recordedAt` — время первого положительного ввода, не измеренное окончание подхода. Старые записи без этих полей остаются совместимыми. Сопоставление выполняется вне приложения по времени старта ±60 с, с проверкой типа и длительности; при нескольких кандидатах нужна ручная проверка. Garmin activity ID и данные пульса не запрашиваются приложением напрямую. При редактировании существующей записи сохраняются исходные метки и имеющийся `garminActivityId`. Данные тренировок не отправляются в GitHub.
